# waves2Foam + HOS 耦合：完整使用说明

> 本说明对应仓库中的 `HOSwaves2Foam/` 模块与 `HOSwaves2Foam/tutorials/`
> 下的两个算例，用 OpenFOAM v2206 + waves2Foam 验证通过。
> （“玻璃场”按“波浪场”理解：本说明第 6 节专门讲怎么设置波浪场。）
>
> **Grid2Grid 全部参数速查见 [HOS-Grid2Grid参数详解.md](HOS-Grid2Grid参数详解.md)。**

## 1. 这套东西是什么

### 1.1 总体链路

```text
HOS 势流模型（HOS-NWT / HOS-ocean，LHEEA-ECN 开源）
        │  用高阶谱方法算出非线性波浪的谱模态（mode 文件）
        ▼
Grid2Grid 数据桥（LHEEA-ECN 开源，编译成 libGrid2Grid.so）
        │  运行时读 mode 文件，在查询点重构波面 η、速度 U、动压 pd
        ▼
libwaves2FoamGrid2Grid.so（本仓库的耦合库，Foam::waveTheories::Grid2Grid）
        │  实现 waves2Foam 的 externalWaveForcing 接口
        ▼
waves2Foam 的 externalSource 波理论 + 松弛区（relaxation zone）
        │  把 HOS 波浪场按权重混入 CFD 域
        ▼
waveFoam / overWaveDyMFoam（VOF 两相流求解）
```

一句话：**HOS 负责“造波”，Grid2Grid 负责“把谱模态变成空间场”，waves2Foam
松弛区负责“把波注入 CFD 计算域”**。

### 1.2 模块里有什么


* HOS-NWT / HOS-ocean 生成 SWENSE mode 文件 →

  教程算例走的就是这条路。

## 2. 快速上手（5 步跑通）

前置条件：OpenFOAM v2206（OpenFOAM+ 分支）、waves2Foam 已编译、cmake、
gfortran、FFTW3（`libfftw3-dev`）、LAPACK/BLAS 静态库。

```bash
# 0) 每次新终端先加载环境
source $HOME/OpenFOAM/OpenFOAM-v2206/etc/bashrc
source $WAVES_DIR/bin/bashrc

# 1) 编译并安装 Grid2Grid（只需一次）
bash HOSwaves2Foam/scripts/buildGrid2Grid.sh
#    产物：$FOAM_USER_LIBBIN/libGrid2Grid.so

# 2) 编译 HOS 波浪模型（HOS-NWT + HOS-ocean，依赖已内置在
#    HOSwaves2Foam/ThirdParty，无需系统安装 FFTW/LAPACK）
bash HOSwaves2Foam/scripts/buildHOS.sh
#    产物：src/HOS-NWT/build/HOS_NWT、src/HOS-ocean/build/HOS_ocean

# 3) 编译 waves2Foam 耦合库
cd HOSwaves2Foam/src/Grid2Grid
wmake libso
#    产物：$FOAM_USER_LIBBIN/libwaves2FoamGrid2Grid.so

# 4) 生成 HOS 波浪数据（HOS-NWT 造波，一次约 1 分钟）
cd HOSwaves2Foam/tutorials/HOS-NWT
#     HOS-NWT 源码在 HOSwaves2Foam/src/HOS-NWT，编译方法见该目录 README.md；
#     编译产物 src/HOS-NWT/build/HOS_NWT 会被 runHOS-NWT.sh 自动找到
bash runHOS-NWT.sh
#    产物：Results/modes_HOS_SWENSE.dat
#    说明：教程 waveFoam-HOS 里已经内置了这份文件，可以跳过本步

# 5) 跑 CFD 算例（blockMesh → setWaveField → waveFoam）
cd HOSwaves2Foam/tutorials/waveFoam-HOS
bash Allrun

# 6) 查看结果
foamToVTK -time 8     # 然后 ParaView 打开 VTK 目录
```

算例跑完 8 s，入口松弛区（x=0..5 m）会看到波高约 0.1 m（振幅 0.05 m）、
周期 2 s 的规则波传入水槽。

### 2.1 教程算例一览

| 算例目录 | 波浪类型 | 说明 |
|---|---|---|
| `tutorials/HOS-NWT/` + `waveFoam-HOS/` | 规则波（A=0.05 m，T=2 s） | 小型 18 m 水槽，入门首选 |
| `tutorials/HOS-NWT-Irregular/` + `waveFoam-HOS-Irregular/` | 不规则波（JONSWAP，Hs=0.05 m，Tp=1 s） | 同一水槽换成不规则波 |
| `tutorials/stokesI-HOS/` | 规则波（H=0.05 m，T=3 s），由 StokesI 改造 | 624 m×200 m 大型水池；`Allrun` 里含可选网格加密 |

每个 CFD 算例的 `constant/modes_HOS_SWENSE.dat` 都已内置，直接
`bash ./Allrun` 即可；HOS-NWT 造波算例用于重新生成数据。

## 3. waveFoam-HOS 算例：配置文件逐行解释

### 3.1 `system/controlDict`

```cpp
application     waveFoam;        // 用哪个求解器
```

### 3.2 `constant/polyMesh/blockMeshDict`

```cpp
convertToMeters 1;               // 1 单位 = 1 m

// 8 个顶点：底面（z=-0.4）4 个 + 顶面（z=0.1）4 个
vertices
(
    (  0 -0.05 -0.4 )   // 0：x=0, y=-0.05, z=-0.4（底角）
    ( 18 -0.05 -0.4 )   // 1：x=18
    ( 18  0.05 -0.4 )   // 2
    (  0  0.05 -0.4 )   // 3

    (  0 -0.05  0.1 )   // 4：顶面（z=0.1，自由面上方 0.1 m 空气）
    ( 18 -0.05  0.1 )   // 5
    ( 18  0.05  0.1 )   // 6
    (  0  0.05  0.1 )   // 7
);

// 一个六面体块：x 方向 180 个单元、y 方向 1 个、z 方向 30 个
// y 必须只有 1 层，且单元中心在 y=0（见 6.4：Grid2Grid 对二维 HOS
// 数据只在 y=0 有定义）
blocks
(
    hex (0 1 2 3 4 5 6 7) ( 180 1 30 ) simpleGrading (1 1 1)
);

patches
(
    patch inlet          { (0 3 7 4) }  // x=0 面 = 造波入口（与松弛区重叠）
    wall bottom          { (0 1 2 3) }  // z=-0.4 海底
    patch outlet         { (1 5 6 2) }  // x=18 出口
    patch atmosphere     { (4 7 6 5) }  // z=0.1 大气顶
    empty frontBack      { (0 4 5 1) (3 7 6 2) }  // y 方向两面 = 空边界（2D）
);
```

要点：块方向顺序是 i→x（0→1）、j→y（1→2）、k→z（0→4），所以写成
`(180 1 30)` 而不是 `(180 30 1)`。

### 3.3 `constant/waveProperties`（核心配置）

这是 waves2Foam 读取波浪配置的字典：

```cpp
seaLevel        0.00;            // 静水面 z 坐标（m）

relaxationNames (inlet outlet);  // 松弛区列表：入口造波 + 出口消波
initializationName outlet;       // 初始场按 outlet（静水）初始化

inletCoeffs                      // 入口松弛区配置（“造波区”）
{
    waveType    externalSource;  // 波类型=外部数据源（即 HOS）
    Tsoft       1;               // 斜坡时间：前 1 s 波幅线性/正弦爬升
    depth       0.400000;        // 水深（m），与 HOS-NWT h、网格一致

    relaxationZone
    {
        relaxationScheme Spatial;   // 空间松弛（沿 x 方向加权混合）
        relaxationShape  Rectangular; // 矩形松弛区
        beachType        Empty;       // 无数值海滩

        relaxType   INLET;           // 入口型（从边到区内衰减）
        startX      ( 0 0 -1 );      // 松弛区起点（x=0，z 覆盖全域）
        endX        ( 5 0  1 );      // 松弛区终点（x=5）
        orientation ( 1.0 0.0 0.0 ); // 松弛方向沿 x
    }
};

outletCoeffs                     // 出口松弛区（吸收，防反射）
{
    waveType    potentialCurrent; // 静止势流（U=0），把波“吃掉”
    U           ( 0 0 0 );
    Tsoft       1;
    relaxationZone { ... relaxType OUTLET; startX ( 13 0 -1 ); endX ( 18 0 1 ); ... }
};

externalForcing  Grid2Grid;      // 选择外部波浪源类型（运行时查表）

Grid2GridCoeffs                  // Grid2Grid 耦合参数
{
    waveType            Grid2Grid;
    Tsoft               1;       // 斜坡时间（s）
    referenceTime       0;       // HOS 时间轴与 OF 时间轴的偏移（s）
    referencePosition   ( 5 0 0 ); // OF 原点在 HOS 坐标系中的位置（m）
    referenceTheta      0;       // OF→HOS 绕 z 的旋转角（度）
    Grid2GridInputFileName Grid2Grid.dict; // 配置文件名（constant/ 下）
}
```

**为什么 `referencePosition (5 0 0)`？** `getGrid2GridPosition` 里
HOS 坐标 = OF 坐标 + referencePosition。于是 CFD 的 x=0..5（松弛区）
对应 HOS 水槽的 x=5..10——避开造波机附近的近场，取已发展的波浪。
如果想把松弛区放在 HOS 水槽的其他位置，改这个向量即可。

**为什么 `referenceTime 0`？** 官方 `Grid2Grid::step()` 用**原始 OF 时间**
去更新 Grid2Grid 内部索引，而 `eta()/U()` 用 `time + referenceTime` 查询；
两者不一致会错位（表现为样条时间越界或取到错误时刻）。保持
`referenceTime = 0` 最稳妥。

### 3.4 `constant/Grid2Grid.dict`（Grid2Grid 数据桥配置）

```text
Grid2Grid       HOSNWT;      // 数据来自 HOS-NWT（另一选项 HOSOcean）

{
    zMin           -0.4;      // 最低 z（= 水深）
    zMax            0.1;      // 最高 z（必须 > 0！要伸到自由面上方）
    nZMin           21;       // 水面以下 z 方向节点数
    nZMax           21;       // 水面以上 z 方向节点数
    zMeshType         uniform;// 均匀网格（或 meshRatio：近自由面加密）
    zMinRatio       3.0;      // meshRatio 时的加密比（均匀网格下不生效）
    zMaxRatio       3.0;
}

HOSOcean { ... }             // 用 HOS-ocean 时的配置块（本例未用）

HOSNWT                       // 用 HOS-NWT 时的配置块
{
    type            NWT;

    interpolationOrder  3;     // 样条阶数：3=三次样条
    $zMesh                     // 引用上面 zMesh 块
    writeLog        TRUE;      // 写 Grid2Grid 日志
}

{
    startTime       0.0;       // 数据起始时间
    endTime		    12.0;      // 数据结束时间（HOS-NWT 的 T_stop）
    dt              0.01;      // 数据参考步长（实际步长以 mode 文件头为准）
}

vtkMesh { ... }                // writeVTK=true 时的输出网格（本例关闭）
waveProbe { ... }              // 波高测点（本例未用）
velocityProbe { ... }          // 速度测点
pressureProbe { ... }          // 压力测点
```

### 3.5 `Allrun`（一键脚本）逐行

```bash
. $WM_PROJECT_DIR/bin/tools/RunFunctions   # 引入 runApplication 等函数

# 自动定位 waves2Foam 根目录（本算例在 HOSwaves2Foam/tutorials/waveFoam-HOS，
# 向上三级就是 waves2Foam 根）
if [ -z "$WAVES_DIR" ]; then
    WAVES_DIR="$(cd ../../.. && pwd)"
fi
. $WAVES_DIR/bin/bashrc noPrint  # 加载 WAVES_* 环境变量（noPrint=不打印）

# 准备 0/ 初始场：把 0.org 里的模板改名成 OpenFOAM v2206 要的文件名
mkdir -p 0
rm -f 0/*
sed 's/object      alpha.org;/object      alpha.water;/' \
    < 0.org/alpha1.org > 0/alpha.water   # 相分数场
cp 0.org/p_rgh.1706.org 0/p_rgh          # 动压场（OF+ ≥1706 用 1706 版本）
cp 0.org/U.org 0/U                       # 速度场

# 复制 OpenFOAM+ 版本对应的离散格式/求解器设置
cp system/fvFiles/fvSchemes.1706 system/fvSchemes
cp system/fvFiles/fvSolution.1706 system/fvSolution

# 复制两相物性（水/空气密度、粘度、表面张力）
cp $WAVES_DIR/tutorials/commonFiles/transportProperties.23 constant/transportProperties

runApplication blockMesh        # 1. 画网格（读取 blockMeshDict）
runApplication setWaveField     # 2. 初始化波浪场（会实例化 Grid2Grid 模块）
runApplication waveFoam         # 3. 跑求解器（每次时间步松弛区注入 HOS 波）
```

出现这几行说明 mode 文件读取成功。

## 4. HOS-NWT 算例：配置逐行解释

### 4.1 `input_HOS-NWT.dat` 参数表

HOS-NWT 的输入是“键值”格式，每行 `说明 :: 关键字 :: 数值`，全部是
**物理单位（米、秒、赫兹）**：

| 关键字 | 含义 | 教程取值 |
|---|---|---|
| `xlen` | 水槽长度（m） | 20.0 |
| `ylen` | 水槽宽度（m） | 1.0 |
| `h` | 水深（m） | 0.4 |
| `icase` | 算例类型：1 晃荡 / 2 规则波 / 3 文件谱 / 4 不规则波 | 2 |
| `islosh` / `aslosh` | 晃荡模态/振幅（icase=1） | 3 / 0.2 |
| `amp_mono` | 规则波**振幅**（m，波高 = 2×振幅） | 0.05 |
| `nu_mono` | 规则波频率（Hz，周期 T=1/nu） | 0.5 |
| `theta_mono` | 传播方向与 x 轴夹角（度） | 0 |
| `ph_mono` | 初始相位（rad） | 0 |
| `ibat` | 造波机类型参数 | 2 |
| `xd_mono` | 目标聚焦距离（ibat=3） | 18 |
| `file_name` / `i_cut` / `nuc_low` / `nuc_high` | 文件谱（icase=3） | 未用 |
| `Hs` / `Tp` / `gamma` / `iseed` | 不规则波：有义波高/谱峰周期/JONSWAP 峰升因子/随机种子 | 未用 |
| `i_wmk` | 造波机非线性阶数 | 1 |
| `igeom` | 造波机类型：1=平动活塞式，2=铰接式 | 1 |
| `d_hinge` | 铰接轴距底部距离（m，仅 igeom=2） | 0.2 |
| `iramp` / `Tramp` | 是否斜坡 / 斜坡时长（s） | 1 / 2.0 |
| `iabsnb` / `xabsf` / `coeffabsf` | 数值消波海滩开关 / 起点比例 / 强度 | 1 / 0.75 / 1.0 |
| `iprobes` / `pro_file` | 是否布测点 / 测点文件 | 1 / prob.inp |
| `T_stop` | 模拟总时长（**物理秒**） | 12.0 |
| `toler` | RK45 时间步容差 | 1e-6 |
| `f_out` | 输出频率（Hz，决定 mode 文件时间分辨率） | 20 |
| `idim` | 1=有量纲输出 | 1 |
| `i3d` | 自由面 3D 图 | 0 |
| `imodes` | 写 Tecplot 格式谱模态（`Results/HOS_modes.dat`） | 1 |
| `iwmk` | 写造波机运动 | 0 |
| `i_sw` | **SWENSE 输出开关（=1 才写 Grid2Grid 要的 mode 文件）** | 1 |

**关键约定**：

* 给 Grid2Grid 的文件是 `Results/modes_HOS_SWENSE.dat`（`i_sw=1`），
  不是 `Results/HOS_modes.dat`（`imodes=1` 那个是 Tecplot 后处理格式）。
* `T_stop` 要足够长：波浪以相速度 c≈ω/k 传播，必须覆盖
  “到达耦合区 + CFD 全程”所需时间。教程里耦合区在 HOS x=5..10，
  波速约 1.8 m/s，12 s 数据足够（波前锋约 22 m）。
* 浅水小水池里铰接造波机（igeom=2）容易发散，教程用活塞式（igeom=1）。

### 4.2 `prob.inp` 与 `runHOS-NWT.sh`

`prob.inp` 每行一个测点 `(x y)`（m），HOS-NWT 会输出
`Results/probes.dat` 的波高/速度/压力时序。

`runHOS-NWT.sh` 做的事：

```bash
set -e                                   # 任何一步失败就退出
HOSNWT_BIN=${1:-$HOSNWT_BIN}             # 可执行文件路径（参数 1 或环境变量）
mkdir -p Results                         # 输出目录
"$HOSNWT_BIN"                            # 运行（从当前目录读 input_HOS-NWT.dat）
# 最后检查 Results/modes_HOS_SWENSE.dat 是否生成
```

## 5. 耦合库代码说明（每段在做什么）

### 5.1 `src/Grid2Grid/Grid2Grid.H`（类声明）

```cpp
class Grid2Grid : public externalWaveForcing  // 继承 waves2Foam 外部强迫基类
{
protected:
    const IOdictionary& waveProps_;   // 指向 constant/waveProperties
    const dictionary& coeffDict_;     // 指向其中的 Grid2GridCoeffs 子字典
    const scalar seaLevel_;           // 静水面
    vector g_;                        // 重力（检查 -z）
    scalar rhoWater_;                 // 水密度（从 transportProperties 读）
    const scalar Tsoft_;              // 斜坡时间
    const scalar referenceTime_;      // 时间对齐
    const vector referencePosition_;  // 坐标对齐
    const scalar referenceThetaRad_;  // 旋转角（弧度）
    const word Grid2GridInputFileName_; // Grid2Grid.dict
    tensor transMatrixToOF_;          // HOS→OF 旋转矩阵
    tensor transMatrixFromOF_;        // OF→HOS 旋转矩阵
    int indexGrid2Grid_;              // Grid2Grid 库内部句柄

    // 接口函数（waves2Foam 会调用）：
    virtual void step();              // 每个时间步：让 Grid2Grid 内部推进
    virtual scalar eta(const point&, const scalar&) const;   // 波面
    virtual vector U(const point&, const scalar&) const;     // 速度
    virtual scalar pExcess(const point&, const scalar&) const; // 动压
    bool implementPressure() const { return true; }          // 支持压力强迫
    virtual bool writeData(Ostream&) const { return true; }
};
```

### 5.2 `src/Grid2Grid/Grid2Grid.C`（实现）

**构造函数**（每步含义）：

```cpp
Grid2Grid::Grid2Grid(IOobject io, Time& rT, const fvMesh& mesh)
:
    externalWaveForcing(io, rT, mesh),        // 基类：保存 Time 和 mesh 引用
    waveProps_(io.db().lookupObject<IOdictionary>("waveProperties")), // 读波浪字典
    coeffDict_(waveProps_.subDict("Grid2GridCoeffs")),               // 取子字典
    seaLevel_(readScalar(waveProps_.lookup("seaLevel"))),
    Tsoft_(coeffDict_.lookupOrDefault<scalar>("Tsoft", 0.0)),
    referenceTime_(coeffDict_.lookupOrDefault<scalar>("referenceTime", 0.0)),
    referencePosition_(coeffDict_.lookupOrDefault<vector>("referencePosition", vector::zero)),
    referenceThetaRad_(coeffDict_.lookupOrDefault<scalar>("referenceTheta", 0.0) * M_PI/180.0),
    Grid2GridInputFileName_(coeffDict_.lookup("Grid2GridInputFileName")),
    transMatrixToOF_(tensor::zero), transMatrixFromOF_(tensor::zero)
{
    mappingTensors(referenceThetaRad_);   // 构造旋转矩阵 + 检查重力 -z
    // 从 transportProperties 的 water 相读密度（后续 pExcess 用）
    // 拼出 constant/Grid2Grid.dict 的完整路径
    // 调用 Fortran：__modgrid2grid_MOD_initializegrid2griddict(path, &index)
    //   —— 让 libGrid2Grid 读 mode 文件、建好重构网格
}
```

**`mappingTensors`**：读重力矢量，要求指向 -z（否则报错）；把
`referenceTheta` 变成绕 z 的旋转矩阵，并求逆矩阵，用于 OF↔HOS 坐标互转。

**`getGrid2GridPosition`**：

```cpp
vector xx = transMatrixFromOF_ & (x + referencePosition_); // OF坐标→HOS坐标
Grid2GridX = xx.x();
Grid2GridY = xx.y();
Grid2GridZ = xx.z() - seaLevel_;   // 减去静水面，得到相对自由面的 z
```

**`getGrid2GridTIme`**：`time + referenceTime`，把 OF 时间映射到 HOS 时间轴。

**`step()`**：每个时间步调用一次
`__modgrid2grid_MOD_correctgrid2grid(&index, &meshTime)`，让 Grid2Grid
内部把谱模态推进到当前时刻（注意：传的是**原始 OF 时间**）。

**`eta()`**：`gethoseta` 取波面 → 乘斜坡 `factor(time)` → 加 `seaLevel`。

**`U()`**：`gethosu` 取速度 → 乘斜坡 → 用 `transMatrixToOF_` 旋转回 OF 坐标。

**`pExcess()`**：`gethospd` 取动压 → 乘斜坡 → 加静水压 `rho*g*seaLevel`。

**`factor()`**：

```cpp
factor = sin( 2*M_PI/(4*Tsoft) * min(Tsoft, time) );  // 0→1 的正弦斜坡
```

## 6. 后续怎么设置波浪场

### 6.1 规则波：改“波高、周期”

波高和周期在 **HOS-NWT 侧**改，改完重跑 `runHOS-NWT.sh` 并重新拷贝
`modes_HOS_SWENSE.dat`：

```text
Amplitude (m) of wave train  :: amp_mono  :: 0.10   // 波幅=波高/2，H=0.2 就写 0.10
Frequency (Hz) of wave train :: nu_mono   :: 0.40   // 周期 T=1/0.4=2.5 s
```

CFD 侧对应检查：

* 网格 z 范围要覆盖 `-h` 到“静水面+波高一半+余量”：zMax ≥ seaLevel + H/2 + 0.02；
* 松弛区要覆盖整条波传播路径上你想注入的 x 段；
* `T_stop` ≥（波到达耦合区时间 + CFD endTime + 余量）。

波长由色散关系决定（水深 h 和周期 T 给定后）：

```text
ω² = g·k·tanh(k·h)，ω = 2π/T，波长 L = 2π/k
```

例如 h=0.4、T=2 s → k≈1.7 → L≈3.7 m。教程网格 dx=0.1 m，约 37 个
单元/波长，足够。一般规则波建议 ≥ 20~30 单元/波长。

### 6.2 不规则波（JONSWAP 谱）

把 `icase` 改成 4，并设置：

```text
Choice of computed case       :: icase  :: 4
Significant wave height (m)   :: Hs     :: 0.05
Peak period (s)               :: Tp     :: 1.0
Shape factor (Jonswap)        :: gamma  :: 3.3
Seed number for random numb.  :: iseed  :: 513
```

注意：

* `T_stop` 要更长（不规则波需要几十个谱峰周期才有统计意义）；
* CFD `endTime` 相应延长；
* Grid2Grid 链路不变，mode 文件格式一样；
* 想换谱（Pierson-Moskowitz 等）需要改 HOS-NWT 源码里的谱生成部分。

### 6.3 斜浪 / 三维波浪

* 斜浪：`theta_mono` 设成传播方向与 x 轴的夹角；同时把
  `Grid2GridCoeffs.referenceTheta` 设成一样的角度，让 OF↔HOS 坐标对齐。
* 三维（y 方向有变化）：默认 HOS-NWT 的 `n2=1`（y 方向 1 个模态），
  只有 y=0 中线的数据。要做 3D 波浪，需要：
  1. 改 HOS-NWT `sources/variabledef/common_vars.f90` 里 `n2`（如 32），
     重新编译 HOS-NWT；
  2. `ylen` 按需要加宽；
  3. CFD 网格 y 方向多层，覆盖 HOS 水槽的 y 范围；
  4. Grid2Grid 会自动用 3D 样条（`isHOS2D_` 判定来自 mode 文件头的 n2）。

### 6.4 坐标系与网格的三条铁律

1. **重力必须沿 -z**：`constant/g` 和 `environmentalProperties` 都写成
   `(0 0 -9.81)`，否则 `Grid2Grid::mappingTensors` 直接报错；
2. **二维（n2=1）时 CFD 网格 y 方向必须只有 1 层且中心在 y=0**：
   Grid2Grid 的 2D 样条只在 y=0 有定义，y 方向有厚度就会“y value out of
   bounds”（其实内部是样条第二维/时间越界一类的问题）；
3. **Grid2Grid.dict 的 zMax 必须 > 0**：z 网格要覆盖自由面上方空气侧，
  否则报 `zMax should be positive`。

### 6.5 松弛区与坐标对齐参数

```text
referencePosition   (5 0 0)    // OF x=0 → HOS x=5：把耦合区移到已发展的波浪区
referenceTheta      0          // 斜浪时与 theta_mono 一致
referenceTime       0          // 保持 0（见 3.3 的说明）
startX / endX                  // CFD 里松弛区的 x 范围（要落在 mode 数据覆盖区）
```

### 6.6 时间与数值

* HOS-NWT `f_out`（如 20 Hz）决定 mode 文件时间分辨率，保证每周期至少
  10~20 个数据点；
* CFD `endTime` 覆盖波浪传播到松弛区之后若干周期；
* `Tsoft`（waves2Foam 与 HOS-NWT 各有一个斜坡）用来避免启动冲击；
* 自适应时间步 `maxCo 0.25`、`maxAlphaCo 0.5` 是常用稳妥取值；
* 浅水小水池慎用铰接造波机（教程用活塞式）。

## 7. 常见问题（FAQ）

| 现象 | 原因 / 解决 |
|---|---|
| `zMax should be positive` | `Grid2Grid.dict` 的 `zMax ≤ 0`，改成 `seaLevel+余量`（>0） |
| `Bad value during floating point read`（mode 文件） | 文件不是 SWENSE 格式。HOS-NWT 要 `i_sw=1`，用 `modes_HOS_SWENSE.dat` |
| `Error evaluating 2D eta spline ... out of bounds` | 时间/坐标不在样条域：检查 `referenceTime=0`、网格 y 中心在 0、zMax>0、`T_stop` 覆盖 |
| 跑完 2 s 发现水面全平、没有波 | 波还没传到松弛区：加长 CFD `endTime`，并确认 HOS-NWT `T_stop` 足够 |
| `Unknown type of external wave forcing: Grid2Grid` | 忘了在 `controlDict` 加 `libs ("libwaves2FoamGrid2Grid")`，或库没编译 |
| 铰接造波机 NaN | 浅水/特定频率下传递函数近奇异，改用活塞式 `igeom=1` 或换频率/水深 |
| HOS-NWT 编译报 PURE/SAVE 错误 | 去掉 `-fno-automatic`（见 4.3） |
| HOS-NWT 编译报 `MOD ... shall not be zero` | 修 `dealiasing.f90` 的除零保护（见 4.3） |
| gfortran `.mod0` 改名失败 | `mkdir -p build/lib` 且 `-j1` 单线程构建 |
| 链接找不到 `-llapack/-lblas` | 用 `CMAKE_LIBRARY_PATH` 指向含静态库目录并加 `-L` |
| `setWaveParameters` 处理不了 `externalForcingCoeffs` | externalSource 场景直接手写 `constant/waveProperties`（教程已这样做），不必跑 setWaveParameters |
